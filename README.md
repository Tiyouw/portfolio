# 🌐 Portfolio - Belajar HTML & CSS

Portfolio website sederhana dibuat dengan **HTML dan CSS vanilla** (tanpa framework).
Cocok untuk belajar dasar web development.

## 📁 Struktur File

```
portfolio/
├── index.html        # Halaman utama (semua section)
├── css/
│   └── style.css     # Semua styling
└── README.md         # File ini
```

## 🚀 Cara Pakai

1. Clone repo ini:
   ```bash
   git clone https://github.com/Tiyouw/portfolio.git
   ```

2. Buka `index.html` di browser.

3. Edit `index.html` untuk ganti konten (nama, skill, proyek).

4. Edit `css/style.css` untuk ganti warna dan tampilan.

## 🎨 Fitur

- **Dark theme** modern
- **Responsive** — tampil bagus di HP dan desktop
- **4 section** — Home, About, Skills, Portfolio
- **Form kontak** — bisa dikoneksikan ke Formspree atau EmailJS
- **Vanilla JavaScript** — hamburger menu & active nav highlight
- **Well-commented** — kode dikomentari biar gampang dipelajari

## 🛠️ Teknologi

| Teknologi | Fungsi |
|-----------|--------|
| HTML5 | Struktur halaman |
| CSS3 | Desain & styling |
| JavaScript | Interaktivitas (menu & scroll) |

## 📚 Yang Dipelajari

- **HTML**: `<nav>`, `<section>`, `<form>`, semantic tags
- **CSS**: Flexbox, CSS Grid, Media Query, CSS Variables
- **JavaScript**: DOM manipulation, Event Listener, `scroll` event
- **Git**: Version control dasar
- **GitHub**: Repository & deployment
